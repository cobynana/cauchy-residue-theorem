01 / 基礎鋪墊

複積分 ∮Cf(z) dz 到底在做什麼？

複平面與極點

z = x + iy 將數線擴展為二維平面；使分母為零、數值發散的孤立點稱為極點（例：1/(z − i) 在 z = i 處發散）。

圍道積分的實質：向量累加

將逆時針封閉路徑 C 切成許多小位移 Δzk，每一步計算複數乘積 f(zk)·Δzk（複數相乘＝長度伸縮與角度旋轉），再將沿途所有微小向量頭尾相接累加：

∮Cf(z) dz =  limΔzk→0  ∑k f(zk) Δzk

核心懸念

走完封閉一圈後，這些沿路累積的複數向量究竟會彼此抵銷歸零，還是會留下非零餘額？

02 / 核心直覺 I

有極點 vs. 沒極點：為何積分會從 0 突變？

無極點時（柯西積分定理）

圍道內部處處解析時，前半圈累積的貢獻會被後半圈反向精準抵銷，繞完一圈必回到原點：

∮Cf(z) dz = 0

包住極點時（對稱抵銷被打破）

以 f(z) = 1/z 為例，只要 C 包覆極點 z = 0，沿途貢獻不再抵銷，繞完一圈立刻跳變為非零常數：

∮Cdzz = 2πi

關鍵對照：同一個函數、同一個圓圈，只差在「有沒有把極點圈進去」，結果就從 0 跳到 2πi。

圍道變形：為何大圈等於極點小圓之和？

02 / 核心直覺 III

繞極點小圓一圈：為何只有 1/z 項「殘留」？

在極點 z0 附近展開為羅倫級數（Laurent Series）：

f(z) = ⋯ + a−2(z − z0)2 + a−1z − z0 + a0 + a1(z − z0) + ⋯

令 z − z0 = reiθ，沿小圓繞一圈，每一項的微小貢獻為：

(z − z0)n dz = i rn+1 ei(n+1)θ dθ

n ≠ −1 微小向量隨角度旋轉整數圈，
頭尾相接走回原點：積分歸零。 n = −1 相位因子化為 ei·0 = 1，所有微小向量
沿同一方向 +i 累加：唯一殘留 2πi·a−1。

無論展開式有無限多項，繞極點一圈後所有 n ≠ −1 項全數歸零，唯一存活的係數 a−1 即為留數（Residue）。

03 / 實務計算

不用展開級數：單極點「遮蓋法」雙例演練

實務上求留數不需展開完整羅倫級數。若 z0 為單極點（Simple Pole）：

Res(f, z0) =  limz→z0 (z − z0) f(z)

三步驟操作（遮蓋法／Cover-up Method）

1將分母進行因式分解，標出極點位置。 2遮蓋（消去）分母中導致發散的一次因式 (z − z0)。 3將 z = z0 代入剩餘表達式，即得留數。

右側例題 A、B 的留數將直接用於第 9、10 頁。

註：若 z0 為 m 階極點（例如分母含 (z − z0)2），遮蓋一次仍會發散，須改用：

Res(f, z0) = 1(m−1)!  limz→z0 dm−1dzm−1[(z − z0)mf(z)]

04 / 實戰一：驗算基準

求解問題 A：∫∞−∞dx1 + x2 = π

策略：先用已知答案的題目驗證留數定理。

步驟一　建構上半平面半圓圍道 CR

由實軸 [−R, R] 與上半圓弧 ΓR 構成；當 R → ∞，圓弧積分趨近於零：

|∫ΓRdz1 + z2| ≤ πRR2 − 1 ⟶ 0

04 / 實戰二：真正威力

攻克問題 B：∫∞−∞cos x1 + x2 dx = πe

① 複數化改寫：利用歐拉公式 eix = cos x + i sin x

J = ∫∞−∞eix1 + x2 dx,  I2 = Re J

② 為何上半圓弧貢獻仍為零？（約旦引理直覺）

在上半平面 z = x + iy（y ≥ 0）：|eiz| = |eix|·e−y = e−y ≤ 1，往上走只會指數衰減、絕不發散，故

|∫ΓReiz1 + z2 dz| ≤ πRR2 − 1 ⟶ 0

③ 代入第 8 頁例題 B 的留數（圈內唯一極點 z = i）

J = 2πi·Res(eiz1 + z2, i) = 2πi·e−12i = πe

④ 取實部得精確解

∫∞−∞cos x1 + x2 dx = πe ≈ 1.1557 附贈：∫ sin x/(1+x2) dx = Im(π/e) = 0

04 / 工程與科學應用

走出考卷：留數如何決定真實系統行為？

控制系統與訊號處理

二階阻尼系統的轉移函數與兩個極點：

H(s) = ω(s + 1)2 + ω2,  s = −1 ± iω

以留數加總做拉普拉斯反轉換，直接得到脈衝響應：

h(t) =  ∑sk=−1±iωRes[H(s)est, sk] = e−tsin(ωt)

物理與波動力學

格林函數的極點下移至 ω0 − iε：t < 0 上方閉合、無極點得 0（結果不早於原因）；t > 0 下方閉合，拾取留數。

解析數論與級數求和

選取核函數 π cot(πz)/z2，把無窮和轉成 z = 0 的留數，得到巴塞爾問題 ∑ 1/n2 = π2/6。
